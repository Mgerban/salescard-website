1. Security approach

SalesCard applies security measures proportionate to a mobile CRM service, including account authentication, role-aware access, secure session handling, encrypted network transport and limited administrative access.

2. Mobile and local data

Local storage supports responsive and offline-capable workflows. Supported sensitive session material is stored using platform security facilities where available. Users should protect their devices with a passcode, biometric unlock and current operating system updates.

3. Cloud services

Cloud services support account operation, synchronisation, collaboration and integrations. Access to production systems is limited to authorised operational purposes.

4. Integrations

Google and Microsoft connections use provider-authorised access. Users can disconnect supported integrations and revoke access through the relevant provider account.

5. Responsible reporting

Suspected security vulnerabilities should be reported privately to info@sales-card.com . Please do not access, modify or disclose another person’s data while investigating a potential issue.
